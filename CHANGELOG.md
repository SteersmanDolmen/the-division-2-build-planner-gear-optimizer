# Changelog

## [1.0.0] — November 2026

### Added
- Gear builder with six slots, brand sets, core attributes and minor rolls
- Weapon comparison with damage per magazine, RPM, reload and distance bands
- Talent planner for chest, backpack and weapon talents with conflict warnings
- Loadout presets with duplication and two-click switching
- Build export as readable text and as a compact file
- Role templates for DPS, skill and tank builds
- Auto-backup of the build library before every save
- Native C++ build, 6 MB, no runtime dependencies
