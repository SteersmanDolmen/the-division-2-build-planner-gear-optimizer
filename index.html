Features

Everything a build needs, on one rounded sheet

Six slots, two weapons, five talents and a dozen attributes add up to millions of combinations. The planner keeps them together so you compare builds instead of guessing.

Gear builder

Pick a brand set and a gear slot, set the core attribute, then stack minor rolls the way the game allows. The sheet flags duplicate core attributes and impossible rolls before you favorite a piece in game.

Weapon comparison

Place two weapons side by side and read damage per magazine, RPM, reload and the talent in one table. Distance bands are separated, so an SMG does not silently win a fight it never reaches.

Talent planner

Map chest, backpack and weapon talents, and see which ones cancel each other out.

Loadout presets

Save a finished build as a preset, duplicate it, and swap the variant in two clicks.

Build export

Copy the whole build as readable text or a compact file for your group.

FAQ

Before you download

Does the planner touch the game or my account?

No. It is a standalone desktop app that stores builds in its own local library. It does not read game memory, inject files, log in to your account or send anything over the network.

Do I need the game running?

No. The planner works with the published stat data and your own inputs, so you can plan a build while the game is closed or not installed.

Can I keep several builds?

Yes. The library holds as many presets as you like, each with its own gear sheet, weapons and talents. Duplicate one to test a variant without losing the original.

What format is the export?

Plain text and a compact file for the app. The text version lists every slot, brand, core attribute and talent so it can be pasted into a group chat.

Are the damage numbers exact?

They follow the published formulas and are close but not identical to the game after every balance pass. Treat them as a comparison tool, not a scoreboard.

Where does the library live?

Next to the executable inside the extracted folder, with a timestamped backup created before each save. Move or copy the folder and the library moves with it.
